# Agent instructions

This repository follows Davide Caputo's house standards. The full spec is
[`reference/STYLE.md` in Repo-Standards](https://github.com/CaputoDavide93/Repo-Standards/blob/main/reference/STYLE.md)
(private). When this summary and the spec disagree, the spec wins.

## Rules that apply to every change

- **Documentation never lies.** Every command, flag, feature, count and badge must be true of the code. Verify before writing; delete what you can't verify. No hand-typed counts that can drift.
- **Commits:** conventional (`fix:`, `feat:`, `docs:`, `refactor:`, `ci:`, `chore:`), authored by the repo owner. No co-author trailers, session ids or "generated by" lines in commits, PRs, issues or comments.
- **Never** force-push the default branch, commit secrets, or change runtime identifiers (env var names, container and image names, public URLs) as a side effect.
- **Secrets:** never put a secret, key, token, IP address, private host name, family name or personal e-mail in `AGENTS.md`, docs or code. The one public contact address is the single exception. `.gitignore` carries the secrets block.
- Run the repo's own checks before and after; anything green before stays green.
- This repository is public. `tools/scrub.py` fails on private identifiers (generic rules in the file, private words only in the git-ignored `.deny-local`, never in a tracked file); do not add real folder names, addresses or personal paths to code, tests, docs or screenshots.

## README

- Centered header: one emoji H1, a **bold** one-line tagline, flat shields.io badges (no `style=`), then `---`. No Apple logos or icons anywhere; the trademark notice stays.
- Emoji `##` headings, `---` between sections, a repo tree in a `text` block that matches `git ls-files` (`tests/test_hygiene.py` checks it).
- The README ends with `---` and the credit line exactly as it is now. No star request, no extra lines.

## Layout and naming

- Directories `lowercase-kebab`; docs `docs/lowercase-kebab.md`; shell scripts `kebab-case.sh`; Python `snake_case`.
- Root holds only README, LICENSE, SECURITY, CONTRIBUTING, CHANGELOG, AGENTS (`.md`) plus config files. No vendor-specific agent file.
- One `.env.example` with every variable the code or compose file reads.

## Commands

- Setup: `make setup` (Python 3.11+, creates `.venv` with the lint tool)
- Gate: `make check` (lint, tests, scrub, diagram)
- Tests only: `make test`; lint: `make lint`; scrub: `make scrub`
- Packaging: `make docker-smoke` (throwaway image and container, cleans up)
- UI: `make ui-setup`, then `KEEPSAKE_CHROMIUM=<chromium binary> make ui-test`
- Screenshots: `KEEPSAKE_CHROMIUM=<chromium binary> make screenshots`
- Diagram: `python3 tools/gen_diagram.py` (and `--check`)

## Layout

- `src/keepsake/engine.py`: the sync engine. Every guard has an attack fixture in `tests/test_engine.py`; a change here needs a test that fails without it.
- `src/keepsake/config.py`, `service.py`, `server.py`, `notifier.py`, `diagnostics.py`, `__main__.py`: settings and jobs, scheduling and actions, REST API and security, optional notifiers, the redacted diagnostics report, entrypoint.
- `src/keepsake/web/`: the web page (plain HTML, CSS, JS, no build step, no external requests, no inline styles or scripts: the content security policy forbids them).
- `tests/`: unit and API tests (`unittest`), `tests/ui/smoke.mjs` for the headless-browser check.
- `docs/`: start at `docs/README.md`.

## Conventions

- Standard library only at runtime. Adding a dependency needs a reason in the PR.
- Python 3.11+ (the engine uses `shutil.rmtree(dir_fd=...)`).
- Refusals are plain sentences and are never reportable as success.
- `accept_shrink`, `adopt_existing`, `delete_copy` count only as the JSON boolean `true`.

## Do not touch

- Runtime identifiers: `KEEPSAKE_*` variable names, the marker file names `.keepsake-owner`, `.keepsake-group` and `.keepsake-anchor`, the `Keepsake` folder name in iCloud Drive: renaming them orphans existing copies.
- Generated files: `docs/assets/architecture-{light,dark}.svg` (by `tools/gen_diagram.py`).

## Secrets

- Real values live only in the git-ignored `.env`; `.env.example` lists every variable with a fake placeholder.
